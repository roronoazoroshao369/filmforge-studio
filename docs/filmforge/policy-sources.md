## Content release gate

Before publishing an original episode:
1. Source script is original or has explicit adaptation rights; no fan-film monetization by assumption.
2. Characters, images, AI-generated likeness, voice, music, fonts, stock footage and game/movie clips have documented commercial publishing rights.
3. Video is editorially distinct and does not repeat near-identical empty formats.
4. Claims not misleading; synthetic/deepfake disclosure applied when required.
5. Platform-specific music/claim/length/aspect and children's-content rules checked.
6. Human owner reviews final rendered video, title, thumbnail and description, then publishes manually.
7. Record release URL and policy check date; consent/rights artifacts private, not leaked into public repo.

**Copyright ≠ platform monetization.** Owning material or having a license does not guarantee YPP eligibility. No false promise of YouTube profit; actual payout requires account eligibility, review and qualified performance. Revenue is recorded only if verified from the owner’s statements.

## Compliance guardrails for FilmForge

- Default **no mass auto-upload**, no automated engagement, no purchased traffic.
- No private channel API tokens in source; integration requires OAuth review and minimum permissions.
- Keep rights/provenance in project data and release manifest without exposing personal identity.
- Recheck terms periodically; never freeze policy thresholds in product logic without configurable effective dates.
